*locoreview.txt* Local code review comments for Neovim

Requirements: Neovim 0.10+, Git for diff review. Run from your repository.
Setup: require("locoreview").setup({})

COMMENT WORKFLOW                                      *locoreview-comments*

:ReviewAdd             Open a multiline editor at the current line.
:[range]ReviewAddRange Open the same editor for a line range.
:ReviewShow            Read all comments at the current source line.
:ReviewEdit            Edit the first comment at the current source line.
:ReviewList            Open comments in quickfix.
:ReviewListAll         All comments; optional status=, severity=, file= filters.
:ReviewPicker          Pick a comment using an optional picker or vim.ui.select.
:ReviewNext            Next open comment.
:ReviewPrev            Previous open comment.
:ReviewOpen            Open or create the Markdown review file.

In the editor, write the comment above the optional requested-change heading.
<C-s> saves; <C-g> cycles severity; <C-c> cancels. <Esc> enters normal mode;
normal-mode q cancels. A failed save keeps the draft open. Save or discard
unsaved manual review-file edits before changing comments through the plugin.

STATUS COMMANDS                                       *locoreview-status*

:ReviewMarkFixed       Resolve the first open comment at the current line.
:ReviewReopen          Reopen a non-open comment at the current line.
:ReviewMarkBlocked     Mark the first open comment blocked.
:ReviewMarkWontfix     Mark the first open comment wontfix.
:ReviewDelete          Delete a comment after confirmation.
:ReviewClean           Permanently remove every fixed comment.
:ReviewRefresh         Reload signs, quickfix and the open PR view.
:ReviewToggleSigns     Toggle signs for this session.

DIFF REVIEW                                           *locoreview-diff*

:ReviewPR              Staged and unstaged changes against HEAD.
:ReviewPR {base}       Committed changes from base...HEAD.
:ReviewAddDiff         Add only on changed lines against the configured base.

PR view keys:
  c         Add a comment on the current diff line.
  K         Read comments on that line.
  ]f / [f   Next / previous file.
  ]c / [c   Next / previous hunk.
  go        Open current-revision source in a new tab.
  R         Refresh.
  ?         Help.
  q         Close.

Untracked files are not part of the diff. Removed-line comments are anchored
to the old path and revision. Line numbers do not track subsequent source edits.

CONFIGURATION                                         *locoreview-config*

  review_file       "review.md"
  default_severity  "medium" (low, medium, high)
  default_author    nil
  base_branch       nil (auto-detect for diff-only adds)
  diff_only         false
  signs            { enabled = true, priority = 20 }
  picker           { enabled = true, backend = "auto" }
  keymaps           true (false disables; a table overrides individual maps)

Picker backends: auto, telescope, fzf_lua, snacks, none (built-in selection).
Default maps: <leader>ra add, rA visual range, rv show, rl list, rk picker,
rn/rp next/previous, re edit, rf fixed, rr reopen, rD delete, ro review file,
rP PR view, rR refresh, rs signs, rc clean, rb blocked, rw wontfix.

MIGRATION                                             *locoreview-migration*

ReviewShow replaces ReviewOpenDiff (keymap option: show instead of open_diff).
ReviewFix and agent options are removed. PR timers, moods, rhythm modes,
rewards, viewed state and source-file management are removed, along with
pr_view options. Requested-change text is never applied as source code.
Existing Markdown review comments and status values remain supported.
